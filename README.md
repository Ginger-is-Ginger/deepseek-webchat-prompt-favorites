
# 📚 DeepSeek Prompt 收藏夹 (DeepSeek Prompt Favorites)

一个专为 [DeepSeek](https://chat.deepseek.com/) 网页版设计的 Tampermonkey（油猴）用户脚本。它集成在你的输入框旁，帮助你分类、搜索、一键插入并跨设备备份你常用的提示词（Prompt），提升与 AI 交互的效率。

## ✨ 功能特性

* **无缝集成**：完美融入 DeepSeek 原生 UI，按钮精准锚定在上传文件按钮（回形针形状）左侧，不影响原有输入体验。
* **分类管理**：将提示词标记为「前缀」、「内容」、「后缀」，方便在不同场景下组合使用。
* **智能搜索**：在收藏夹内置搜索框，支持关键词快速过滤，告别翻找。
* **一键注入**：点击任意收藏的提示词，即可自动插入（或追加）到当前的对话输入框中。
* **双语文切换**：内置「中/EN」切换按钮，界面文字随时切换，**不影响**已保存的Prompt数据。
* **数据安全与备份**：提供导出与导入功能（JSON 格式），方便你随时备份数据或在不同的电脑/浏览器之间迁移。

## 🚀 安装指南

1. **安装用户脚本管理器**：
   * 如果你使用 Edge 或 Chrome，请在扩展商店搜索并安装 [Tampermonkey](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd)。
2. **安装本脚本**：
   * 你可以点击此处从 [GreasyFork](链接地址) 安装。
   * 或者直接复制本仓库的 `main.js`（或 `.user.js`）代码，在 Tampermonkey 控制台点击“添加新脚本”，粘贴代码并保存（`Ctrl + S`）。
3. **刷新页面**：
   * 打开 [chat.deepseek.com](https://chat.deepseek.com/)，在输入框左下角（回形针“添加附件”图标左侧）即可看到「📚 提示词收藏夹」按钮。

## 📖 使用说明

* **添加提示词**：点击面板左上角 `+` 号，输入内容，选择分类（前缀/内容/后缀），点击确定。

* **使用提示词**：点击列表中的任意提示词卡片，内容将直接填入输入框。

* **删除提示词**：点击提示词卡片右下角的 `🗑️` 可删除，弹窗确认避免误删。

* **导入/导出**：
  * **导出**：点击面板底部「导出」，将生成一个包含所有数据的 `.json` 文件并下载。
  * **导入**：点击「导入」选择 `.json` 文件。脚本会询问你是「追加」还是「覆盖」现有列表，请谨慎选择。

* **切换语言**：点击搜索框右侧的 `中/EN` 按钮即可实时切换界面语言。


## 🔒 隐私与数据说明

* **本地存储**：你的所有提示词数据均保存在浏览器的 `Local Storage` (`ds_prompts_v1`) 中。**本脚本不包含任何服务端代码，不会收集、上传或分析你的任何提示词内容。**
* **清理提醒**：请注意，如果你在浏览器设置中清理了“Cookie 及其他网站数据”，你的提示词也会被清空。**建议定期使用「导出」功能进行备份。**
你可以将以下内容直接添加到 `README.md` 文件的 **“📖 使用说明”** 部分（建议放在“导入/导出”下面），作为一个独立的子章节。这样其他开发者或用户就能清楚地知道备份文件的数据结构。


## 📦 导出的 JSON 数据格式

当你点击“导出”按钮时，脚本会将本地所有的提示词数据打包成一个标准的 `.json` 文件。该文件是一个数组（Array），内部包含了你收藏的每一个提示词对象。

一个典型的导出文件内容如下：

```json
[
  {
    "id": "1715691234567",
    "content": "请将以下内容翻译成英文：",
    "tag": "前缀"
  },
  {
    "id": "1715691234568",
    "content": "请参考附件PDF，完成以下工作：\n1. 总结核心观点\n2. 提取重要数据",
    "tag": "内容"
  },
  {
    "id": "1715691234569",
    "content": "确保回复格式为Markdown，并使用中文。",
    "tag": "后缀"
  }
]
```

**字段说明：**

*   **`id`** (`String`)：系统生成的唯一标识符（时间戳 + 随机字符）。如果需要手动新增条目，建议使用随机字符串或最新的时间戳，避免冲突。
*   **`content`** (`String`)：提示词的具体文本内容。支持包含换行符（`\n`）。
*   **`tag`** (`String`)：提示词的分类标签。**注意：** 为了保证跨语言切换时的数据兼容性，本地存储和导出的 `tag` 值始终为中文的 `"前缀"`、`"内容"` 或 `"后缀"`。即使你在英文界面下导出，这三个字段的值也不会变成英文，脚本在渲染时会自动将其显示为 `Prefix`、`Content` 或 `Suffix`。

> 💡 **进阶提示**：你可以利用文本编辑器（如 VS Code）直接打开并批量编辑这个 JSON 文件，修改完毕后，再通过“导入”功能覆盖回脚本。**请务必保持上述的字段名和 JSON 结构不变，否则会导致导入失败。**
